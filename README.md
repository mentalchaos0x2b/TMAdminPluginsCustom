# TMAdmin Custom Plugins Repository (`TMAdminPluginsCustom`)

Кастомный репозиторий плагинов для расширенной среды TMAdmin.

## Содержимое
- Репозиторий: `https://github.com/mentalchaos0x2b/TMAdminPluginsCustom`
- `index.json` — официальный реестр совместимых кастомных плагинов.
- `sources/` — исходные коды тестовых плагинов:
  1. `custom.hello-custom` («Тестовый блок Custom Repo»)
  2. `custom.quick-notes-mini` («Быстрые заметки (Custom)»)
